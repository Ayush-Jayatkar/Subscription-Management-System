# API documentation

Base URL: `http://localhost:8000/api/v1`

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/health` | Confirms the API process is responding |
| GET | `/system/status` | Reports API and PostgreSQL connectivity |

Interactive OpenAPI documentation is generated by FastAPI at `http://localhost:8000/docs`.

As modules are added, document request/response schemas, authorization requirements, error responses and ownership here.
